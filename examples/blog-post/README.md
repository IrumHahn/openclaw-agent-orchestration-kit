# 4주차 과제 예제 — 내 팀으로 블로그 글 1편

1주차에 만든 팀(총괄 미라 · 조사 · 글 · 이미지 · 검수 · 코딩 담당)으로 **"내 AI 오피스 1주차 후기"** 글 1편을 **발행 승인 직전**까지 만든다. 발행 버튼은 사람이 누른다.

```
A 조사 ──┬── B 초안 ──┐
         └── C 이미지 ─┴── D 조립(미리보기) ── E 독립 검수 ── 총괄 통합 ── [승인 대기]
```

| 스냅샷 | 무슨 일이 있었나 | 배우는 것 |
|---|---|---|
| `active` | A 가 출처 5건을 모아 검수 통과. B·C 가 **동시에** 시작 | 하류는 상류 **검수 통과 후**에만 시작한다 |
| `rework` | B·C·D 가 다 통과했는데, E 가 링크를 전부 클릭해 보니 인용 3번이 404 | 한 번 통과한 것도 **철회**될 수 있고, 그걸 쓴 D·E 는 자동으로 `stale` |
| `integrated` | B 가 v2 로 고치고 D·E 를 다시 만들어 재검수. 총괄이 통합. 발행은 승인 대기 | **버전**이 바뀌면 검수도 다시. 통합 ≠ 발행 |

## 과제로 쓰는 법 (수강생)

1. 총괄 에이전트에게: `이 목표를 agent-orchestration 스킬의 Lite 모드로 진행해줘. 목표: 블로그 글 1편 발행 직전까지. 완료 기준: (1) 모든 인용에 열리는 출처 링크 (2) 이미지 3장 1200px 깨짐 없음 (3) 에디터 미리보기 순서 확인. 발행은 내가 직접 누른다.`
2. 에이전트가 `references/ledger-template.md` 를 복사해 원장을 만들고 A→B/C→D→E 순으로 채우는지 본다.
3. **반드시 반려 1회를 경험한다**: E 가 뭔가를 찾아내게 하라(없으면 일부러 링크 하나를 틀리게 넣어 본다). 반려 후 D·E 가 다시 만들어지는지 확인한다.
4. 발표(목요일): 원장 1장 + 미리보기 캡처 1장 + "반려된 것과 고친 것" 1문장.

## 검증

```bash
node scripts/validate-run.mjs examples/blog-post/sample-run.json examples/blog-post/scenario.json
```

세 스냅샷 모두 `OK` 가 나와야 한다. 데이터를 바꾸려면 `build-scenarios.mjs` 를 고치고 다시 실행한다.
