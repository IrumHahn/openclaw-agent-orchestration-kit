# 수동 원장 템플릿 (Lite / Manual 모드)

총괄 에이전트는 이 파일을 `runs/<날짜>-<짧은이름>.md` 로 복사해 채운다. 표 하나가 곧 운영 기록이다. JSON 검증기는 선택 사항이며, 이 표만으로도 "누가 무엇을 언제 어떤 근거로" 가 남는다.

**규칙 3개**
1. 하류 작업은 상류의 **현재 버전이 검수 통과**한 뒤에만 시작한다. "끝났대요"는 통과가 아니다.
2. 검수자는 만든 사람과 **다른 에이전트**다. 같으면 "독립 검수 아님"이라고 적는다.
3. 상류 버전이 바뀌면 그걸 쓴 하류는 **stale** 로 표시하고 다시 만든다. 지우지 않는다.

## 채우는 순서 (에이전트용)

1. 목표·완료 기준·허용 범위를 먼저 쓴다. 완료 기준이 "눈으로 확인 가능"한지 본다.
2. 작업표에 ID·담당·선행만 먼저 채운다(계획). 순환이 없는지 본다.
3. 선행이 없는 작업(A)만 시작시킨다. 시작 사실(세션 ID 등)을 실행 기록에 적는다.
4. 제출되면 **버전 번호**를 붙이고 검수자에게 넘긴다. 검수 결과는 기준별로 "통과/반려 + 근거 위치 + 시각".
5. 통과한 뒤에만 다음 작업을 시작시킨다. 반려면 새 버전으로 다시.
6. 모든 작업이 통과하면 통합란을 채운다. **발행·발송·결제는 사용자 승인 뒤, 영수증(실제 URL·발송 ID)이 있어야 "전달 완료"**.
7. 끝나면 "다음 총괄이 이어받으려면"을 한 줄이라도 쓴다.
