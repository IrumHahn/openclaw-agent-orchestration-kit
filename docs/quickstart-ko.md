# 15분 퀵스타트 — 에이전트 오케스트레이션 킷

> 여러 에이전트에게 일을 나눠 주고, **남이 검수하고**, 하나로 합쳐서, 진짜 전달됐는지 확인하는 방법. 4주차 "팀 운영 심화"에서 씁니다. 1주차에 팀 온보딩과 대시보드를 먼저 끝내 두세요.

## 그림 한 장

```
     ① 총괄                 ② 전문가들                ③ 독립 검수          ④ 통합            ⑤ 전달 확인
  목표·완료 기준 적기  →  조사 / 글 / 이미지 (병렬)  →  만든 사람 말고   →  총괄이 합치고  →  실제 올라갔나?
  일 나누기                버전 붙여 제출              다른 에이전트가    전체 점검       영수증·URL 확인
                                                        기준별로 OK/반려
```

반려가 나면 ② 로 돌아가 **새 버전**을 만들고, 그걸 쓴 뒤 단계도 다시 합니다. 지우지 않고 기록에 남깁니다.

## 1. 설치 (VPS 터미널, 1분)

```bash
cd ~
git clone https://github.com/IrumHahn/openclaw-agent-orchestration-kit.git
mkdir -p ~/.openclaw/skills
cp -R openclaw-agent-orchestration-kit/skill/agent-orchestration ~/.openclaw/skills/
openclaw skills list      # agent-orchestration 이 보이면 성공
```

`references/` 와 `examples/` 가 같이 복사돼야 합니다(위 명령은 폴더째 복사하므로 괜찮습니다).

## 2. 첫 실행 (OpenClaw 채팅, 5분)

총괄 에이전트(1주차에 만든 메인 비서)에게:

```
이 목표를 agent-orchestration 스킬의 Lite 모드로 진행해줘.
목표: [예: 블로그 글 1편을 발행 직전까지]
완료 기준: [내가 눈으로 확인할 2~4가지]
팀: [예: 조사=리서처, 글=글벗, 이미지=디자이너, 검수=QA]
원장(ledger-template)을 만들어 작업표를 보여주고, 시작 전에 내 확인을 받아줘.
발행·발송은 내가 직접 한다.
```

에이전트가 **원장**(표 하나짜리 마크다운)을 만들어 보여주면 성공입니다.

## 3. 됐는지 확인 (3가지)

1. 원장에 **완료 기준**이 2~4개 있고, 각각 "내가 눈으로 확인할 수 있는가"
2. 작업표에 **검수자 ≠ 담당**인가 (같으면 "독립 검수 아님"이라고 써 있어야 함)
3. 하류 작업이 상류 **검수 통과 후**에 시작했는가 (원장의 시각 순서)

## 4. 반려 1번은 꼭 겪어 보기 (5분)

검수 에이전트가 아무것도 못 찾으면 배우는 게 없습니다. 예제처럼 **출처 링크 하나를 일부러 틀리게** 넣어 보세요. 검수가 잡아내고 → 반려 → 새 버전 → 재검수까지 원장에 남으면 이 킷의 핵심을 다 본 것입니다.

## 용어 10개 (생활 비유)

| 용어 | 뜻 | 비유 |
|---|---|---|
| Run(실행) | 목표 하나를 끝내는 한 판 | 프로젝트 폴더 하나 |
| Task(작업) | 그 안의 할 일 하나, 담당 1명 | 포스트잇 한 장 |
| Artifact(산출물) | 작업 결과물 + **버전 번호** | 파일 v1, v2 |
| Review(검수) | 다른 사람이 기준별로 OK/반려 | 교정 보는 사람 |
| 독립 검수 | 만든 사람 ≠ 검수자 | 자기 시험지 자기가 채점 금지 |
| stale(낡음) | 상류가 바뀌어서 다시 봐야 하는 상태 | 재료 바뀌었으니 요리 다시 |
| Integration(통합) | 총괄이 합쳐서 전체 점검 | 조립 후 시운전 |
| Approval(승인) | 밖으로 나가기 전 사람의 OK | 결재 도장 |
| Delivery(전달) | 실제로 올라감/보내짐, **영수증** 있음 | 송장 번호 |
| 멱등키(중복 방지 키) | 같은 요청이 두 번 와도 한 번만 | 주문번호 |

## 막혔을 때

| 증상 | 해결 |
|---|---|
| 에이전트가 원장 없이 그냥 일을 시작해요 | "먼저 ledger-template 로 원장을 만들어 보여줘" 라고 한 번 더. 스킬 폴더에 `references/ledger-template.md` 가 있는지 확인 |
| 서브에이전트가 돌았는지 모르겠어요 | 원장의 **실행 기록** 표에 세션 ID 가 있어야 합니다. 없으면 "수동 시작"으로 적게 하세요. 추측으로 채우지 않습니다 |
| 검수가 늘 통과만 해요 | 검수자에게 완료 기준을 **기준별로** 증거 위치와 함께 쓰게 하세요. 증거 없는 통과는 통과가 아닙니다 |
| "전달 완료"라는데 블로그에 없어요 | 영수증(실제 URL)이 없으면 전달이 아닙니다. 승인 대기 상태로 되돌리세요 |
